# Athenix – AI Sports Injury Risk Detection Platform  
  
Developed as part of the **Infosys Virtual Internship**, Athenix is an AI-powered sports injury risk detection platform designed to analyze athlete movement, assess injury risk, and provide role-based insights for athletes and sports professionals.  
  
## Milestone 1 – Platform Foundation  
  
### Completed Modules  
- Backend setup using FastAPI  
- Frontend setup using React and Vite  
- PostgreSQL database integration  
- User Registration and Login with JWT Authentication  
- Athlete Profile Management (Create, Read, Update and Delete)  
- Backend and Frontend API integration  
- API validation using Swagger UI  
- Version control using Git and GitHub  
  
**Status:** Milestone 1 Completed  
  
---  
  
## Milestone 2 – Video & Biomechanical Analysis  
  
### Completed Modules  
- Athlete video upload and processing  
- Human pose and movement analysis  
- Extraction of biomechanical movement features  
- Athlete assessment generation  
- Movement quality analysis  
- Integration of analysis results with athlete profiles  
- Assessment data storage and retrieval  
  
**Status:** Milestone 2 Completed  
  
---  
  
## Milestone 3 – Injury Risk Prediction  
  
### Completed Modules  
- Injury risk assessment using athlete movement data  
- Risk score and risk category generation  
- Identification of movement-related risk factors  
- Injury prediction insights  
- Athlete assessment history  
- Risk-based recommendations  
- Assessment report generation  
  
**Status:** Milestone 3 Completed  
  
---  
  
## Milestone 4 – Role-Based Analytics & Reporting  
  
### Completed Modules  
- Role-Based Access Control (RBAC)  
- Dedicated dashboards for Athlete, Coach, Physiotherapist, Sports Scientist and Administrator  
- Biomechanical analytics and performance trend monitoring  
- Injury risk monitoring and recovery reports  
- High-risk athlete alert system  
- Research and assessment reports  
- Administrator user management and platform statistics  
- User profile and notification features  
  
**Status:** Milestone 4 Completed  
  
---  
  
## Technology Stack  
  
- **Frontend:** React, Vite  
- **Backend:** FastAPI, Python  
- **Database:** PostgreSQL  
- **ORM:** SQLAlchemy  
- **Authentication:** JWT, Passlib (bcrypt)  
- **AI / Analysis:** Computer Vision and Biomechanical Movement Analysis  
- **API Testing:** Swagger UI  
- **Version Control:** Git & GitHub  
  
---  
  
## Project Status  
  
Athenix currently provides an integrated workflow for athlete management, movement analysis, injury risk assessment, role-based monitoring, and reporting.
